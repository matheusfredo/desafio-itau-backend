Desafio Backend - Banco Itaú 

Este projeto é uma resolução do desafio proposto pelo Banco Itaú para backend, utilizando Java com Spring Boot.

 Desafio original: [feltex/desafio-itau-backend](https://github.com/feltex/desafio-itau-backend)

## Tecnologias
- Java 17
- Spring Boot
- Maven
- Java Time API (OffsetDateTime)
- JUnit

## Funcionalidades implementadas
- Registro de transações financeiras.
- Cálculo de estatísticas com base nos últimos 60 segundos.
- Estrutura preparada para expansão futura com endpoints REST.
